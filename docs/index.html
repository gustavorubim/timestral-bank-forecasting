Timestral experiments

Timestral-209M forecasting experiments

Zero-shot Timestral-209M vs classical baselines, one-shot multi-step forecasts from many rolling origins, across 12 experiments. Code: github.com/gustavorubim/timestral-bank-forecasting (write-ups in studies/, configs in experiments/, results in outputs/).

Caveats.
  • Known-future covariates are scenario tests: models were given the realised path of the covariates (rates, macro, weather, prices) over the forecast window. That measures how well a model follows a given scenario, not real-time accuracy.
  • AutoARIMA dropped where seasonal ARIMA was too slow on the shared machine: Zillow, Census retail, M5 (and electricity uses MSTL). Those experiments use AutoETS / seasonal naive / MSTL as the baseline, so relative MASE is not comparable 1:1 across rows.
  • Banks: FR Y-9C downloads are CAPTCHA-blocked, so bank data are FDIC call reports of each holding company's bank subsidiaries (nonbank subsidiaries missing; totals run low, especially for Citi and BofA).
  • Timestral-209M weights license (Modified MIT): free use only for companies under $20M/month revenue; larger companies need a commercial license from Mistral. Code is Apache-2.0.
  • Relative MASE = geometric mean over series of model MASE / baseline MASE; <1 means better than the baseline.
